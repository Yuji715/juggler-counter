ジャグラー カチカチくん PWA

公開方法（GitHub Pages）
1. ZIPを展開します。
2. GitHubでリポジトリを作成し、index.html・manifest.webmanifest・sw.js・4つのPNGを同じ階層にアップロードしてCommitします。
3. Settings > Pages > Build and deploymentでDeploy from a branch、main、/(root)を選びSaveします。
4. 公開されたHTTPS URLをスマホで開きます。Android Chromeはメニューからアプリをインストール／ホーム画面に追加、iPhone Safariは共有 > ホーム画面に追加。初回はオンラインで開いてください。

データは端末・ブラウザ・公開URLのオリジンごとに保存されます。同じ公開元で更新する場合は旧保存キーを維持していますが、ローカルHTMLや別サイトからは自動移行されません。収支記録タブのバックアップで今後の移行が可能です。
旧HTMLの収支は旧画面でCSV出力して保管できます（新アプリのJSON復元とは異なります）。

想定差枚は前回の簡易モデルを維持。ブドウは解析推定値、リプレイは共通参考値1/7.298、チェリー取得率30%を初期値とします。機種別の出典は画面に記載。

更新版：収支記録の投資欄に±1,000円ボタンを追加。既存公開先では index.html と sw.js を同じ場所で上書きしてください。開いているアプリをすべて閉じて再度起動すると新しいキャッシュが有効になります。
